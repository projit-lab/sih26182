1. How the Backend Works (Complete Architectural Flow)

The backend orchestrates raw on-chain data collection, bounded topological extraction, mathematical circuit solving, and statutory reporting:

  1. Request Ingestion & Validation: An investigator provides a target address to POST /api/v1/investigate. Pydantic validates the address format across Bitcoin (Base58/Bech32), EVM (0x...), and synthetic test patterns.
  2. Bounded Neighborhood Extraction (SubgraphExtractor):
    • Temporal Causality Filter: Prunes downstream edges where $t_{\text{out}} < t_{\text{in}} - 2\text{h}$, preserving the money-laundering arrow of time.
    • High-Degree Hub Detection: Halts expansion at nodes with $\ge 45$ edges (mining pools, mixers) to prevent combinatorial search explosion ($O(b^k)$).
    • Adaptive Volume Beam Search: Retains outgoing branches until $\ge 85\%$ of candidate volume mass is captured (bounded between 3 and 12 branches), safeguarding peel chains from premature pruning.
  3. Multi-Tier Data Fetcher: Bitcoin queries execute across Mempool.space, Blockstream Info, and Blockchain.info with Proportional UTXO Haircut Apportionment. Ethereum account transfers are ingested via Etherscan API.
  4. Grounded Laplacian Solver ($Lx = b$): Maps the graph into an electrical resistor network where conductances equal transaction volume. Node 0 is grounded (Dirichlet boundary) and Sparse LU factorizes the grounded Laplacian. Effective resistance ($R_{\text{eff}}$) is computed between suspect and each candidate VASP.
  5. Statistical Confidence Normalization: Conductance weighting ($w_i = \frac{1}{R_{\text{eff}} + 10^{-6}}$) normalizes effective resistance into a percentage probability.
  6. Audit, SAHYOG Dispatch (Mock) & Investigator Lead PDF: The case is logged in DuckDB/SQLite; a simulated freeze directive is issued via SAHYOG with a demo hash; a prototype PDF report is compiled.

A. Database Connection & Table Schema (backend/database/db.py)

Thread-safe connection pool with automatic DuckDB $\rightarrow$ SQLite fallback.

def connect(self):
    with self._lock:
        if self._conn is not None:
            return self._conn
        if self.use_duckdb:
            try:
                import duckdb
                self.db_path.parent.mkdir(parents=True, exist_ok=True)
                self._conn = duckdb.connect(database=str(self.db_path), read_only=False)
                return self._conn
            except Exception as e:
                logger.error(f"DuckDB failed: {e}. Falling back to SQLite.")
                self.use_duckdb = False
        SQLITE_DB_PATH.parent.mkdir(parents=True, exist_ok=True)
        self._conn = sqlite3.connect(str(SQLITE_DB_PATH), check_same_thread=False)
        self._conn.row_factory = sqlite3.Row
        return self._conn

# Inverse Resistance Normalization into Probabilities

    c: 1.0 / (attr_result.scores[c] + 1e-6)
    for c in attr_result.ranked_candidates if not math.isinf(attr_result.scores[c])

total_weight = sum(inverse_weights.values()) or 1.0

ranked_items = [
    RankedVaspItem(
        vasp_name=metadata.get(c, {}).get("entity", c),
        candidate_address=c,
        effective_resistance=round(attr_result.scores[c], 4),
        confidence_score=round(inverse_weights.get(c, 0.0) / total_weight, 3),
    )
    for c in attr_result.ranked_candidates
]
